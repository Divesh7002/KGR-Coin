# KGR Coin (KGRC)

KGR Coin is a blockchain-based digital token built on Ethereum using the ERC-20 standard, with a fixed initial supply of 100,000 KGRC tokens, deployed on the Ethereum Sepolia testnet.

**MetaMask Wallet Integration:** The platform enables users to connect their MetaMask wallets, view token balances, import KGR Coin, transfer tokens between wallet addresses, and track blockchain transactions through an interactive dashboard.

The smart contract is developed using Solidity and OpenZeppelin, while the frontend uses HTML, CSS, Tailwind CSS, and Ethers.js.

### Key Features
- MetaMask wallet connection and integration.
- Custom ERC-20 token (KGR Coin – KGRC).
- Fixed supply of 100,000 KGRC.
- Real-time token balance and supply display.
- Token transfers between Ethereum wallets.
- Transaction history with Etherscan links.
- Add KGR Coin directly to MetaMask.
- Ethereum Sepolia testnet deployment.

**Technologies:** Solidity, Ethereum, ERC-20, OpenZeppelin, Remix IDE, MetaMask, HTML, CSS, Tailwind CSS, Ethers.js.
